# Omar Zid robotics work

**First open `00_READ_ME_FIRST.txt`.** It explains every step in simple language.

You only need these files to begin:

1. `00_READ_ME_FIRST.txt` - your short guide and readiness checklist.
2. `Start_Here.html` - the offline computer demonstration. Open it in a browser.
3. `Omar_Zid_Complete_Robotics.pdf` - all reports together.

The `reports` folder contains separate PDF reports and editable Word copies.
Keep the entire folder together so pictures and links continue to work.

## For later

- `code` - NXC programs for a real LEGO NXT; read its README before use.
- `data` - measurements, plots and check results from the simulations.
- `simulation` - the scripts used to calculate the results.
- `sources` - your original assignment screenshots and teaching PDFs.
- `Assignment_Coverage.md` - where each assignment requirement is addressed.

Viewing the demo needs no Python installation or real robot. Replays show saved
simulation results. Python scripts can regenerate data, but do not automatically
refresh the finished reports or embedded replay.

The guide separates computer-demo readiness from real-robot readiness. The NXC
code has not been compiled or tested on a physical robot. Bluetooth is emulated.
The lecture omits frames B and D; the report supplies symbolic formulas for them.
